# Contributing

1. Open or claim an issue.
2. Create `feature/<issue>-<short-name>` from `main`.
3. Keep raw datasets and secrets outside Git.
4. Generate results with scripts; never edit published metrics by hand.
5. Update English and Chinese content together.
6. Open a pull request and ask the other contributor to review it.

For GPU work, mark the issue before implementation and keep training in Colab.
Only lightweight, versioned artifacts return to this repository.
